# 🛍️ HSY SHOP - نظام إدارة الاشتراكات وحساب الأرباح (الجزائر 🇩🇿)

نظام ويب متكامل واحترافي مصمم خصيصاً لمتجر **HSY SHOP** بالدينار الجزائري (**د.ج**) وطريقة تواصل حصرية عبر **ميسنجر (Facebook Messenger)** لإدارة زبائن الاشتراكات الرقمية، متابعة أوقات البدء والانتهاء، إدارة خانات وبيانات الحسابات، وحساب الأرباح الحقيقية ونسب الربح بدقة فورية، مع إمكانية مشاركة الروابط والتقارير مع الأدمن.

---

## 🌟 التحديثات والميزات الجديدة

### 1. 🇩🇿 العملة: الدينار الجزائري (د.ج) فقط
- تم إلغاء جميع العملات الأخرى وتثبيت الحسابات بالكامل بالدينار الجزائري (**د.ج**).
- جميع الإحصائيات، بطاقات المؤشرات المالية، وحاسبة الأرباح تعمل بالدينار الجزائري.
- تسعيرات افتراضية متطابقة مع أسعار السوق الجزائري:
  - **Netflix UHD:** تكلفة 800 د.ج | سعر البيع 1600 د.ج (ربح +800 د.ج | نسبة 50%)
  - **Shahid VIP:** تكلفة 1400 د.ج | سعر البيع 2800 د.ج (ربح +1400 د.ج | نسبة 50%)
  - **IPTV VIP سنة:** تكلفة 2800 د.ج | سعر البيع 5500 د.ج (ربح +2700 د.ج | نسبة 49%)
  - **ChatGPT Plus:** تكلفة 2500 د.ج | سعر البيع 5000 د.ج (ربح +2500 د.ج | نسبة 50%)
  - **Canva Pro:** تكلفة 900 د.ج | سعر البيع 2200 د.ج (ربح +1300 د.ج | نسبة 59%)

### 2. 💬 طريقة التواصل: ميسنجر فقط (Facebook Messenger)
- **التواصل مع الزبائن:** زر مباشر بجانب كل زبون لفتح محادثة ميسنجر فورية (`https://m.me/username`).
- **إرسال الفاتورة والبيانات:** زر "إرسال للزبون عبر ميسنجر" يقوم بنسخ كليشة الفاتورة وبيانات الحساب تلقائياً وفتح نافذة ميسنجر للزبون للصقها وإرسالها فوراً.
- **التواصل مع الأدمن:** حفظ حساب ميسنجر للأدمن، مع زر "إرسال التقرير للأدمن عبر ميسنجر" الذي ينسخ التقرير المالي الشامل ويفتح محادثة الأدمن في ميسنجر بنقرة واحدة.
